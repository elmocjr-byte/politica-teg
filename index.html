Política de Privacidade

Aplicativo: Teacher Elmo Games (pacote br.teacherelmo.englishgamehub)
Responsável: Teacher Elmo Lincoln
Data: 03/11/2026

Resumo

O Teacher Elmo Games é uma biblioteca de jogos educacionais de inglês. O app pede login com e-mail e baixa os jogos de um servidor. Depois de baixados, os jogos funcionam offline.

O que o aplicativo faz com os seus dados

  • O app pede login com e-mail.
  • O servidor guarda o seu e-mail para liberar os jogos.
  • O app baixa os jogos do servidor. É preciso internet para baixar e atualizar; depois de baixados, os jogos funcionam offline.
  • O progresso fica salvo no seu aparelho.
  • Não tem anúncios.
  • Não compartilhamos dados com terceiros.
  • O seu e-mail não é vendido.

Informações guardadas no aparelho

O progresso e as configurações dos jogos ficam salvos apenas no seu aparelho e são apagados quando o aplicativo é desinstalado.

Crianças

O único dado pessoal que o app pede é o e-mail, usado só para o login e para liberar os jogos. Pais e professores devem acompanhar o uso por crianças.

Mudanças nesta política

Se algo mudar, esta página será atualizada com uma nova data.
